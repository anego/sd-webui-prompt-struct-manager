# SD WebUI Prompt Struct Manager (PSM)

Stable Diffusion WebUI (Automatic1111 / Forge) 向けの、プロンプトを構造的に管理するための拡張機能です。
プロンプトやネガティブプロンプトをツリー構造（グループ化）で整理し、ドラッグ＆ドロップでの並べ替えや有効/無効の切り替えを直感的に行うことができます。

本プロジェクトは「Stable Diffusion WebUI reForge」で動作確認しています。

## 主な機能

*   **構造化管理**: プロンプトをグループ（フォルダ）とアイテム（タグ）の階層構造で管理できます。
*   **直感的な操作**: ドラッグ＆ドロップによる並べ替え、階層移動が可能です。ドラッグ中も移動元のレイアウトが崩れないクローン方式を採用し、空のグループにもドロップしやすいよう領域が拡大されます。
*   **移動先クイック選択**: 右クリックの「移動...」から検索付きダイアログを開き、数文字の入力で移動先を確定できます（最近使った移動先5件を先頭に表示、親パス併記、キーボード操作対応）。
*   **有効/無効の切り替え**: 各アイテムやグループごとのON/OFFをワンクリック（またはスペースキー）で切り替えられます。
*   **一括操作**: グループヘッダーのアイコンから、グループ内の全アイテムを一括で有効化・無効化できます。
*   **重み調整（コンパクトスライダー）**: 各プロンプトチップの右横にコンパクトなスライダーUI（`0.1`〜`2.0`）を搭載。リセットボタン「↺」で即座に `1.0` にリセットできます。表示/非表示を設定で切り替え可能で、ブラウザをリロードしても設定が保持されます。
*   **カテゴリ内排他選択（択一モード）**: グループ内のプロンプトを「択一」にできるスイッチ（トグルボタン）を搭載。ONにすると、グループ内のどれか1つを有効化すると他のメンバーが自動的に無効化されます。
*   **プロファイル（状態スナップショット）**: 現在のツリーの有効/無効状態やウェイト設定を「プロファイル」として名前を付けて保存し、ツールバーからいつでも一括適用・削除ができます。
*   **ランダムグループ**: Dynamic Promptsの `{A|B|C}` 構文に対応し、グループ内からランダムにプロンプトを選択する機能を利用できます。
*   **重複チェック**: ツリー内に同一のプロンプトが存在する場合、自動で検出してハイライト表示し、設定により出力をブロックできます。
*   **グループマップ**: 画面右側にツリー構造のナビゲーションを表示し、クリックで対象グループへ瞬時にジャンプできます。
*   **Tag Autocomplete 連携**: `a1111-sd-webui-tagcomplete` 拡張機能が導入されていれば、入力時のタグ自動補完が利用可能です。
*   **反映前プレビュー**: 反映する前に、コンパイル結果の全文と現在のWebUIプロンプトとの差分（追加/削除タグ）を確認できます。トークン数の概算も表示されます。
*   **反映 & 閉じる**: PSM上で構築したプロンプトをWebUIにワンクリックで転送し、パネルを閉じます。
*   **文字列整形**: 連続するカンマを自動的に集約し、綺麗なプロンプトを生成します。
*   **ファイル管理**: プロンプト構成をYAMLファイルとして保存・読み込み・複製・リネームできます。
*   **キーボード操作**: 矢印キーでの移動、F2での編集、Deleteでの削除など、キーボードショートカットに対応しています。
*   **Animaモデル対応**: ファイル単位のモデルモード切替（SD系 / Anima）、Anima推奨タグ順序でのカテゴリ整列、テンプレート作成に対応しています（下記「Animaモデル対応」参照）。
*   **プロンプト翻訳（日→英）**: ローカルLLM（Ollama / LM Studio等）またはクラウドAPI（OpenAI互換 / DeepL）で、日本語の自然言語プロンプトを英訳できます。
*   **PNG Info 取込**: 生成画像のパラメータ文字列を貼り付けるだけで、プロンプトを解析して構造化して取り込めます（下記「PNG Info 取込」参照）。
*   **自動グループ化**: タグDB（`a1111-sd-webui-tagcomplete`）を利用して、タグをカテゴリ・サブ分類（髪／服装／ポーズ など）へ自動振り分けできます。ローカルLLMによる補完にも対応。

## Animaモデル対応

[Anima](https://huggingface.co/circlestone-labs/Anima)（CircleStone Labs × Comfy Org のアニメ特化モデル）向けの機能群です。SD系モデルでの従来動作には影響しません。

*   **モデルモード（ファイル単位）**: サイドバーのトグルで `SD系` / `Anima` を切り替え。YAMLの `model_mode` に保存され、未設定の既存ファイルは自動的にSD系として扱われます。
*   **スコアタグ等の保護**: Animaの `score_7` やPony系の `score_8_up`、顔文字タグ（`^_^` 等）、LoRA構文（`<lora:name_v2:0.8>`）のアンダーバーが、スペース置換で壊れないよう保護されます（モード共通・常時有効）。
*   **自然言語アイテム**: 編集モーダルの「自然言語モード」をONにすると、アンダーバー置換・括弧エスケープ等をスキップして長文をそのまま出力します。Animaの自然言語プロンプトに最適です。
*   **カテゴリ整列**: グループに `品質/メタ/年代/安全`・`主体`・`キャラクター`・`作品`・`絵師`・`一般` のカテゴリを設定でき、Animaモード時のみ、反映時にAnima推奨順（quality → subject → character → series → artist → general）でルート直下を自動整列します。ツリーの表示順は変わりません。
*   **Animaテンプレート**: 新規ファイル作成時に「Animaテンプレートで作成」をONにすると、カテゴリ設定済みのグループ雛形と公式推奨の品質タグ・ネガティブタグ入りで初期化されます。

## PNG Info 取込

ツールバーの「PNG Info」ボタンから、生成画像のパラメータ文字列（PNG Infoタブの内容）を貼り付けてプロンプトを構造化して取り込めます。

*   **自動解析**: Positiveプロンプト、`Negative prompt:` 行、`Steps: 20, Sampler: ...` の生成設定行を自動判別します（複数行・設定行なしにも対応）。
*   **構文の復元**: 強調構文 `(smile:1.2)` はウェイトへ変換、`((detailed))` `[dark]` も `1.1^n` で概算。エスケープ括弧 `\(...\)` は元の括弧へ戻り、`<lora:...>`・ワイルドカード・`BREAK` は分解されません。長文は自動的に自然言語アイテムになります。
*   **カテゴリ別グループ化**: タグDBの判定結果で品質・主体・キャラクター・作品・絵師・一般のグループへ振り分けます（Animaモードでは既定ON）。
*   **「一般」の細分化**: 髪／顔・表情／体／服装／装飾品／ポーズ／構図／小物／背景／光・色／画風／効果／文字の13分類＋その他へ自動振り分けします。
*   **タグ名の日本語化**: 翻訳機能を使って英語タグの意味を「名前」欄へ設定できます（20件ずつ一括翻訳、進捗表示付き）。

## 自動グループ化 (タグDB / AI)

`a1111-sd-webui-tagcomplete` が導入されていると、タグのカテゴリを自動判定できます（任意機能。未導入時はメッセージで案内されます）。

*   **カテゴリ自動判定**: グループ編集モーダルのボタンで、配下タグの多数決からカテゴリを提案します（判定内訳も表示）。
*   **カテゴリ一括判定**: サイドバー（Animaモード時）から、カテゴリ**未設定**のグループのみを一括判定します。
*   **サブ分類でグループ化**: グループを右クリック →「サブ分類でグループ化」で、配下のタグを髪・服装・ポーズなどのサブグループへ再編成します。既存のサブグループや自然言語アイテム、`<lora:...>` は元の位置に残ります。
*   **AI補完**: 翻訳設定にOpenAI互換バックエンド（LM Studio / Ollama 等）があると「AI補完」メニューが追加され、**ルールで判定できなかったタグのみ**をローカルLLMへ問い合わせます（リクエスト数を抑えたハイブリッド方式）。

## プロンプト翻訳機能

自然言語アイテムの編集画面に「原文」欄と「英訳 →」ボタンが追加され、日本語で書いた文章を英語プロンプトへ変換できます。

*   **ローカル / クラウドの2プロファイル**: サイドバーの「翻訳設定」で、ローカルLLM用とクラウドAPI用の設定を両方保持し、トグルひとつで切り替えられます。
*   **対応バックエンド**: OpenAI互換API（Ollama / LM Studio / llama.cpp server / OpenAI / OpenRouter 等）と DeepL API。プリセット選択でエンドポイントが自動入力されます。
    *   LM Studio利用時のモデル名は、`http://localhost:1234/v1/models` で確認できるモデル識別子（`id`）を入力してください。
*   **設定の保存先**: APIキーを含む翻訳設定はブラウザのlocalStorageにのみ保存され、サーバー側やリポジトリには残りません。クラウド利用時はプロンプトが外部送信される旨の注意が表示されます。
*   **接続テスト**: 設定パネルから短文の試訳で疎通確認ができます。エラー時はサーバーからの詳細メッセージを表示します。
*   **原文の保持**: 翻訳前の原文はアイテムの `sourceText` として保存され、WebUIへの出力には含まれません。

## インストール方法

1.  SD WebUIの `Extensions` タブを開きます。
2.  `Install from URL` タブを選択します。
3.  `URL for extension's git repository` に本リポジトリのURLを入力します。
4.  `Install` ボタンを押します。
5.  `Installed` タブに戻り、`Apply and restart UI` をクリックしてWebUIを再起動します。

## 使い方

Extensionをインストールすると、WebUI上に「📂 PSM」ボタン（または専用の開閉ボタン）が表示されます（※UIの配置による）。

![Basic Operations](assets/PSM_basic_operations.gif)

サイドバーの「言語 (Language)」切り替えスイッチで、日本語と英語を切り替えることができます。

### 初回セットアップ (Initial Setup)

拡張機能をインストールして最初の起動時、または設定ファイル (`config.json`) が存在しない場合、自動的にセットアップウィザードが表示されます。

1.  **保存先ディレクトリの選択**: プロンプトデータ (YAMLファイル) を保存するフォルダを指定します。
2.  **初期ファイルの作成**: 最初に作成するファイル名（例: `prompts`）を入力します。

ウィザードを完了すると、指定したフォルダに設定が保存され、すぐに使用を開始できます。

### 基本操作

*   **追加**: ルートまたグループの「ADD PROMPT」ボタン、または右クリックメニューから「新規プロンプト」「新規グループ」を追加します。
*   **編集**: アイテムをダブルクリック、または選択して `F2` キーで編集モードに入ります。
*   **削除**: アイテムを選択して `Delete` キー、または右クリックメニューから削除します。
*   **移動**: アイテムをドラッグ＆ドロップで並べ替えるか、右クリックメニュー「移動...」から移動先を検索して指定できます。ダイアログでは検索欄にフォーカスが当たるので、数文字入力して `Enter` で移動できます（`↑` `↓` で選択、`Esc` で閉じる）。
*   **ドラッグ＆ドロップのコツ**: ドラッグ中は移動元のレイアウトが保持されるため、狙った位置がずれません。閉じたグループはグループ名にしばらくホバーすると自動展開され、専用のドロップゾーンも表示されます。空のグループもドラッグ中は領域が広がるため、そのままドロップできます。
*   **サブ分類でグループ化**: グループを右クリックして「サブ分類でグループ化」を選ぶと、配下のタグを髪・服装・ポーズなどへ自動で振り分けます（`a1111-sd-webui-tagcomplete` が必要）。
*   **グループの並べ替え**: グループヘッダーにある「▲」「▼」ボタンをクリックして、グループの並び順を変更できます。
*   **有効化/無効化**: アイテム左側のチェックボックス、または選択して `Space` キーで切り替えます。
*   **カテゴリ内排他選択（択一モード）**: グループヘッダーの右端にあるトグルボタンをクリックしてON/OFFを切り替えます。 ONにすると、そのグループ内のアイテムを有効化した際、他の兄弟アイテムが自動的に無効化されます。
*   **ウェイト調整**: 各プロンプトチップの右横のスライダーをドラッグするか、スライダー右端にある「↺」ボタンをクリックして `1.0` にリセットします。スライダーを表示したくない場合は、設定（歯車アイコン）の「重みスライダーを表示」をOFFにします。この設定は自動的に記憶されます。
*   **プロファイルの管理**: ツールバーのプロファイルドロップダウンから現在の状態を保存（「Save Current as Profile」）したり、保存済みのプロファイルを選択して一括適用したり、不要なプロファイルを削除できます。
*   **反映 & 閉じる**: `Ctrl + Shift + Enter` でプロンプトをWebUIに反映し、PSMパネルを閉じます。（生成は実行しません）

### キーボードショートカット

*   `↑` `↓`: フォーカスの移動
*   `→`: グループを展開
*   `←`: グループを折りたたみ
*   `Space`: 有効/無効の切り替え
*   `F2`: 編集モード開始
*   `Ctrl + Enter`: 編集モード確定
*   `Delete`: 削除確認
*   `Insert`: 新規アイテム追加 (Shift+Insertでグループ追加)
*   `Shift + F10`: コンテキストメニュー表示
*   `Ctrl + Shift + Enter`: WebUIへ反映して閉じる (Apply & Close)

### ファイル保存 (Storage)

サイドバーのファイルリストから、現在の構成を `.yaml` ファイルとして保存できます。
「Storage」セクションでは、YAMLファイルの保存先フォルダを変更できます。フォルダアイコンをクリックして選択するか、パスを直接入力してください。

*   **リフレッシュ**: ファイルリスト横の更新ボタンで、ディレクトリ内のファイル一覧を再読み込みします。

## 連携する拡張機能 (任意)

| 拡張機能 | 効果 |
| --- | --- |
| [a1111-sd-webui-tagcomplete](https://github.com/DominikDoom/a1111-sd-webui-tagcomplete) | 入力時のタグ補完。加えてタグDBを参照したカテゴリ判定・サブ分類による自動グループ化が有効になります |
