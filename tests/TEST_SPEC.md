# 📘 Prompt Struct Manager (PSM) 品質保証仕様書 (v2.0)

**最終更新日:** 2026-06-13
**検証範囲:** 3層の自動テストスイート（単体テスト、バックエンドテスト、E2Eテスト）

---

## 1. テスト戦略
PSM Ver2の品質保証は、デグレードの防止、UIの一貫性、およびAPIの安定性を保証するために、3層に分かれた階層的な自動テストアーキテクチャの上に構築されています。
- **バックエンドAPIテスト (pytest):** サーバー設定、ファイルI/O操作、およびプロンプトのコンパイルロジックの安定性を保証します。
- **フロントエンド単体テスト (Vitest):** モック環境下で、カテゴリ内排他選択、プロファイル復元、重複検出、ローディングインジケーターカウンタ制御などのコアなビジネスロジックの状態制御を検証します。
- **E2Eテスト (Playwright):** ヘッドレスブラウザを制御し、実際のユーザーインタラクション、ドラッグ＆ドロップ、ウィジェット描画（コンパクトなウェイトスライダーなど）、キーボードショートカット、プロンプト大辞典とのポータル双方向連携、およびタイピング中・削除時の誤閉鎖防止、長文編集アイコンの表示制御を検証します。

---

## 2. テストスイートとテストシナリオ

### 2.1 バックエンドテスト (`pytest` - 16件)
- **API設定:** `get-config` および `set-config` のロジック、保存先フォルダー構造、およびフォールバック先の検証。
- **YAML I/O:** YAMLファイルの安全な保存/読み込み、ファイル内の `profiles` 項目の統合、ファイルの複製、リネーム、および削除の検証。
- **文字列解析:** ポジティブ/ネガティブプロンプトのクリーンアップ、ウェイト値に対する丸括弧の自動付与、および Dynamic Prompts 構文の変換処理の検証。

### 2.2 フロントエンド単体テスト (`Vitest` - 24件)
- **基本操作:** ストア状態におけるノードの追加、編集、削除、およびドラッグ移動の検証。
- **カテゴリ内排他選択 (択一モード):**
  - 排他グループ内の1つのアイテムを有効化すると、他のすべての兄弟要素が自動的に無効化されることを確認。
  - すでに複数の有効なアイテムが存在するグループで択一モードを有効にした際、最初の1つだけを残して他の有効アイテムが自動的に無効化クリーンアップされることを確認。
- **プロファイルスナップショット:**
  - スナップショットのキャプチャ（`saveProfile`）、プロファイル適用時の状態一括復元、およびプロファイルの削除機能の検証。
- **重複チェック:** `none` (無効), `warn` (警告表示), `error` (ブロック) の各モード切り替え時の挙動検証.
- **ローディング制御:** ファイルの初期読み込み処理中に `isLoading` と `loadingText` カウンタ状態制御が正しく連動し、日常的な保存処理（`savePrompts`）ではスピナーが表示されずユーザー操作をロックしないことを検証（2件）。
- **コンパイルフォーマット (アンダーバー置換):** プロンプト内容のアンダーバーから半角スペースへの自動置換、および Dynamic Prompts ワイルドカード (`__wildcard__`) でのアンダーバー保護を検証（1件追加）。

### 2.3 E2Eテスト (`Playwright` - 12件)
- **セットアップウィザード:** 初回起動時の保存先フォルダー設定画面が表示され、正常に保存できることを検証。
- **ファイル管理 (CRUD):** サイドバーのボタンを通じてファイルを作成、リネーム、および削除できることを検証。
- **スライダー操作:** コンパクトスライダーをドラッグした際、ウェイト値がリアルタイムに更新され、WebUIへのコンパイル時に `(word:weight)` 形式で反映されることを検証。
- **プロファイル UI ワークフロー:** ツールバーから新しいプロファイルスナップショットを作成、適用し、状態が変化すること、およびプロファイルを削除できることを検証。
- **ドラッグ＆ドロップ (DaD) 復元:** 新しいクラス `.psm-node__drag-handle` への適応、グループ/フォルダのドラッグハンドル機能、およびフォルダを跨いだノードのネスト・並び替えが正しく機能することを検証。
- **キーボードショートカット:** `F2` での編集開始、`Space` での有効/無効切り替え、`Insert` での新規プロンプト作成など、標準ショートカットキーのマッピングを検証。
- **キーボードタイピング安全性の検証:** プロンプト名前入力欄や本文テキストエリアで `m` キーや `Enter` などを入力した際に、グローバルショートカットが誤作動せず、PSMモーダルが閉じないことを検証。
- **削除確認時の誤閉鎖防止の検証:** プロンプト削除時に確認ダイアログ（`delete-confirm-modal`）で「削除」を押してダイアログを閉じても、PSMメインパネル自体が誤作動で連動して閉じないことを検証。
- **プロンプト大辞典双方向連携の検証:** モーダル展開時に大辞典がポータル要素に即時移動（マージ）し、大辞典の「挿入」ボタンをクリックしたときにPSMのテキストエリアへカンマ区切りでタグが安全に挿入されること、またモーダル閉鎖時に自動回収機能と競合せず、元の親要素（`txt2img_actions_column` など）へ正しく復元され折りたたまれることを検証。
- **独立検索フィルターの検証:** サイドバー共通のグローバル検索を廃止し、Positive / Negative のそれぞれのペインヘッダーに検索入力欄が独立して設置され、入力中にヘッダーの開閉トグルが発生せず、ペイン折りたたみ時にはフィルターが非表示になることを検証。
- **大辞典挿入時の名前自動コピーの検証:** プロンプト大辞典の検索入力欄にキーワードを入力して「挿入」を押した際、編集モーダルのプロンプト本文にタグが挿入されるとともに、プロンプトの名前フィールドが空の場合にのみ自動で検索キーワードがコピーされ、既に名前がある場合は上書きされないことを検証。
- **編集アイコン表示保護の検証:** プロンプトの名前や内容が極端に長い場合でも、レイアウト制限（テキスト幅の縮小、`flex-shrink-1` の適用、アイコンへの `flex-shrink-0` 適用）によって、編集（鉛筆）アイコンが画面外に押し出されずに常に表示・クリック可能であることを検証（1件追加）。

## 3. テストの実行方法
実行コマンドの詳細は [doc/DEVELOPMENT.md](../doc/DEVELOPMENT.md) を参照してください。
- フロントエンド単体テスト: `npm run test:unit`
- バックエンドAPIテスト: `pytest` (venv環境下では `..\..\venv\Scripts\python -m pytest`)
- E2E統合テスト: `npx playwright test tests/design.spec.ts`
- 一括実行スクリプト (Windows): `.\test_local.bat`
