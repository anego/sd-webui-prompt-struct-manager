# 📘 Prompt Struct Manager (PSM) 品質保証仕様書 (v3.0)

**最終更新日:** 2026-10-31
**検証範囲:** 2種類の自動テスト（フロントエンド単体テスト、バックエンドテスト）＋ リリース前の手動確認

---

## 1. テスト戦略
PSMの品質保証は、ロジックを自動テストで、画面表示と操作を手動確認で担保する構成です。
- **バックエンドAPIテスト (pytest):** サーバー設定、ファイルI/O操作、およびプロンプトのコンパイルロジックの安定性を保証します。
- **フロントエンド単体テスト (`bun test`):** モック環境下で、ツリー操作、カテゴリ内排他選択、プロファイル復元、重複検出、ローディングインジケーターカウンタ制御などのコアなビジネスロジックの状態制御を検証します。
- **手動確認 (チェックリスト):** 見た目（色・枠線・レイアウト）、キーボード/マウス操作、プロンプト大辞典など他拡張との連携といった、ブラウザ上でしか確認できない項目を、リリース前に [2.3 手動確認チェックリスト](#23-手動確認チェックリスト) に沿って確認します。

> v1.6.0 で Playwright による E2E テストを廃止しました（開発環境の Bun 移行に伴い、Bun ランタイムが Playwright の公式サポート外のため）。E2E が検証していた内容のうち、UI を介さずに検証できるロジックは単体テストへ移し、残りを手動確認チェックリストに置き換えています。

## 2. テストスイートとテストシナリオ

### 2.1 バックエンドテスト (`pytest` - 125件)
- **API設定:** `get-config` および `set-config` のロジック、保存先フォルダー構造、およびフォールバック先の検証。
- **YAML I/O:** YAMLファイルの安全な保存/読み込み、ファイル内の `profiles` 項目の統合、ファイルの複製、リネーム、および削除の検証。
- **文字列解析:** ポジティブ/ネガティブプロンプトのクリーンアップ、ウェイト値に対する丸括弧の自動付与、および Dynamic Prompts 構文の変換処理の検証。
- **保存高速化 (書き込みキャッシュ):** `save-prompts` がディスクI/Oを行わずキャッシュのみ即座に更新すること、`flush-prompts` での明示的flush、`get-prompts` のread-your-own-writes一貫性、複製/リネーム/削除がキャッシュの保留中変更を正しく扱うこと（古い内容のコピー事故・削除後のファイル復活を防止）、シャットダウンイベントでの一括flushを検証（`test_psm_cache.py`にキャッシュ単体のデバウンス動作テストを追加）。
- **YAML→JSON移行:** `.json`ファイルの読み書き、`list-files`が`.yaml`/`.json`両方を対象としつつ`generation_profiles.json`を除外すること、`convert-to-json`での変換（保留中の未flush変更が反映されること、変換元は残ること、変換先の上書き拒否）、複製/リネームで拡張子省略時に変換元と同じ形式が補完されることを検証。

### 2.2 フロントエンド単体テスト (`bun test` - 203件)
- **基本操作:** ストア状態におけるノードの追加、編集、削除、およびドラッグ移動の検証。
- **カテゴリ内排他選択 (択一モード):**
  - 排他グループ内の1つのアイテムを有効化すると、他のすべての兄弟要素が自動的に無効化されることを確認。
  - すでに複数の有効なアイテムが存在するグループで択一モードを有効にした際、最初の1つだけを残して他の有効アイテムが自動的に無効化クリーンアップされることを確認。
- **プロファイルスナップショット:**
  - スナップショットのキャプチャ（`saveProfile`）、プロファイル適用時の状態一括復元、およびプロファイルの削除機能の検証。
- **重複チェック:** `none` (無効), `warn` (警告表示), `error` (ブロック) の各モード切り替え時の挙動検証。
- **ローディング制御:** ファイルの初期読み込み処理中に `isLoading` と `loadingText` カウンタ状態制御が正しく連動し、日常的な保存処理（`savePrompts`）ではスピナーが表示されずユーザー操作をロックしないことを検証（2件）。
- **コンパイルフォーマット (アンダーバー置換):** プロンプト内容のアンダーバーから半角スペースへの自動置換、および Dynamic Prompts ワイルドカード (`__wildcard__`) でのアンダーバー保護を検証（1件追加）。
- **検索フィルターのグループ開閉状態スナップショット/復元:** フィルター開始時に各グループの開閉状態を`id`単位で記録し、フィルターによる自動展開後もフィルター解除時に元の開閉状態（ネストしたグループを含む）へ正しく復元されること、およびフィルター中に追加された新規グループは復元対象外となることを検証（4件追加）。
- **グループマップ集計 (`groupMapUtils.ts`):** ネストしたグループの有効プロンプト数が、子の集計結果を再利用した単一パスの走査で旧実装と同じ結果になること（祖先が無効な場合に子孫グループ自身の集計は独立して保たれること等）を検証（`groupMapUtils.spec.ts`、10件追加）。
- **一括無効化の確認フロー:** `requestDisableAll` の時点では何も無効化・保存されないこと、`confirmDisableAll` で対象ペインが無効化・保存され確認待ちが解除されること、`cancelDisableAll` では何も変更されないこと、確認待ちが無い/2回目の確定では何も実行されないことを検証（5件追加）。
- **起動時の初期化 (`initializePsm`):** 前回選択ファイルがある場合でも `get-prompts` が1回だけ実行されること、生成設定プロファイルの読み込み、初期設定未完了時・前回ファイルが一覧に無い時に読み込まないことを検証（4件追加）。
- **保存高速化 (フェーズC):** `createPromptFile`が拡張子省略時に`.json`をデフォルトとすること、`duplicateCurrentFile`/`renameCurrentFile`が`.yaml`固定ではなく複製・変更元と同じ拡張子を継承すること、`convertCurrentFileToJson`の成功/エラー各パスを検証。
- **リアクティブProxyと元配列の同一性:** ロック判定(`isListLocked`)・移動先の子孫判定・D&Dの移動確定で、Vue のリアクティブProxyと元の配列が混在しても同じリストとして正しく判定されることを検証。
- **アイテムの追加・編集・複製・削除 (旧E2Eからの移行):** `addItem` の末尾/指定位置への追加とプロンプト/グループの作り分け、`startEdit`/`finishEdit`/`cancelEdit` による確定・キャンセル（新規追加のキャンセルで空アイテムが取り除かれること、括弧を含む内容が保存時にエスケープされないこと）、`duplicateItem` による直後への複製とIDの再採番（グループは子孫ごと独立して複製）、削除確認→実行/キャンセル、グループ枠のみ削除時の子要素の昇格を検証（14件追加）。
- **グループ内一括有効/無効・重複チェックモード切替 (旧E2Eからの移行):** `setGroupChildrenEnabled` が入れ子を含む配下を一括で切り替えて保存すること、ロック中のグループは変更しないこと、`setDuplicateCheckMode` がモードを切り替えてローカル設定に保存し、既存の重複ハイライトを消すことを検証（3件追加）。

## 3. テストの実行方法
実行コマンドの詳細は [doc/DEVELOPMENT.md](../doc/DEVELOPMENT.md) を参照してください。
- フロントエンド単体テスト: `bun run test:unit`
- バックエンドAPIテスト: `pytest` (venv環境下では `..\..\venv\Scripts\python -m pytest tests\`)
- 手動確認: `bun run build` 後に WebUI をリロードし、[2.3 手動確認チェックリスト](#23-手動確認チェックリスト) を一巡する
